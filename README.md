# Mint messenger

<img src="https://github.com/mawsom777/mint/blob/main/materials/header.jpg" height="150" width="1680">
Mint - это веб-мессенджер с возможностью совершать аудио- и видеозвонки, а аткже обмениваться текстовыми сообщениями (в личных чатах, группах, каналах) и файлами (с превью изображений).

---

## 🚀 Возможности

- Личные чаты, группы и каналы  
- Отправка файлов с предпросмотром картинок
- Аудио‑ и видеозвонки (WebRTC + TURN/STUN)  
- Реальное время через **Server‑Sent Events (SSE)**  
- Статус «онлайн» и «прочитано»
- Редактирование и удаление сообщений  
- Push‑уведомления через **Firebase Cloud Messaging**  
- Авторизация по **JWT** (access + refresh токены)  
- Адаптивная вёрстка (мобильная и десктопная версии)  
- Поддержка сборки в мобильное приложение через **Capacitor**  

## 🧱 Стек технологий
### Backend
- PHP с: `pdo_mysql`, `redis`, `firebase/php-jwt`, `aws/aws-sdk-php`
- MySQL (основная БД)  
- Redis (очереди сигналов, онлайн‑статус, звонки)  
- MinIO (S3‑совместимое хранилище файлов)  
- JWT (аутентификация)  
- Firebase Cloud Messaging (уведомления)  

### Frontend
- HTML5, CSS3 (адаптив, кастомные переменные)  
- JavaScript (нативный, модули)
- Capacitor (для сборки нативных приложений)  
- WebRTC (звонки)  
- Server‑Sent Events (получение обновлений)
- TypeScript (для демонстарции навыков)

## ⚙️ Установка и запуск (для локального тестирования)

1. **Клонируйте репозиторий**  
   ```bash
   git clone https://github.com/mawsom777/mint.git
   cd mint
   ```

2. **Установите зависимости PHP** 
   ```bash
   composer install
   ```

3. **Настройте MySQL**  
   - Создайте базу данных (например, `mint`)  
   - Создайте двух пользователей:  
     - `checker` – только SELECT (для проверок)  
     - `writer` – SELECT, INSERT, UPDATE, DELETE (для записи)  
   - Импортируйте схему из `db_mint.sql`

4. **Установите Redis**  
   - Установите Redis и запустите сервер  
   - При необходимости задайте пароль в конфиге Redis (и пропишите его в `config.local.php`)

5. **Настройте MinIO**  
   - Запустите MinIO сервер  
   - Создайте bucket и укажите ключи доступа

6. **Firebase**  
   - Создайте проект в Firebase, получите сервисный аккаунт (JSON)  
   - Поместите файл в `notifications/service-account-file.json`  
   - Для веб‑версии скопируйте VAPID‑ключ и настройте `/scripts/notifications-web.js`

7. **Конфигурация**  
   - Переминуйте `config.example.php` → `config.local.php`  
   - Заполните все параметры: подключения к БД, Redis, MinIO, пути к сервисному аккаунту Firebase, JWT‑секрет

8. **Настройка фронтенда**
    - Найдите /scripts/config.js
    - Замените baseUrl – адрес вашего сервера (для Capacitor)
    - Для работы звонков потребуются TURN. Для теста указаны STUN сервера. 

9. **Настройте веб‑сервер** (например, Nginx + PHP‑FPM)  
   - Корневая директория – папка проекта  
   - Настройте переадресацию всех запросов на `index.html` (для SPA) и обработку PHP через FastCGI

9. **Готово!**  
   ```
   http://localhost
   ```
